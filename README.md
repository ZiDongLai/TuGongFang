# 图工坊 TuGongFang

Android 图片编辑应用源码（个人开发项目）。

- 稳定基线：v1.0.43（DEV43 FIX1，华为 Mate60 Pro 实测通过）
- 技术：Kotlin、Jetpack Compose、Android Gradle
- 功能概览：单图编辑、自由/模板拼图、文字、信息模板、边框、色轮、自动保存、图片导出
- 打开方式：Android Studio → Open → 选择工程根目录，等待 Gradle Sync 后构建

当前版本为开发阶段源码备份，并不意味着已面向公众正式发布。项目中的图片、图标及其他素材的使用与再分发，取决于各自权利归属；请勿未经确认即授权他人复用。
